# Kosugi Maru

Google Fontsで配布されているKosugi Maru Regularを、`fontslice`で用途別にサブセット化して同梱している。

- `KosugiMaru-Landing.woff2`: ヒーロー専用
- `KosugiMaru-LandingBody.woff2`: ヒーローより下のLP本文専用
- `KosugiMaru-Game.woff2`: 開始準備・問題・回答・結果などの日本語UI用
- `LICENSE.txt`: Apache License 2.0

原本と再生成手順は[`../README.md`](../README.md)を参照。
