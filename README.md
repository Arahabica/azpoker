# 暗算ポーカー

ポーカーのドロー確率を2択で答える、10問1セットのブラウザドリルです。
現在は `PLAN.md` のフェーズ3までを実装した、文字カード版です。

## 起動

追加パッケージは不要です。

```sh
npm run serve
```

ブラウザで `http://localhost:8000` を開きます。

## 検証

```sh
npm test
npm run check:bank
```

問題バンクを再生成する場合:

```sh
python3 scripts/generate_question_bank.py
```

## フェーズ3での仕様判断

- フェーズ表でモードB・Cはフェーズ7に置かれているため、現在の10問はモードAのみです。
- 1セットはプリフロップ2問、フロップ4問、ターン4問です。順番は毎回混ぜます。
- フロップ／ターンは、各ステージ内で同じカテゴリが重ならないように選びます。
- コンボドローは、フラッシュとストレートの両方を完成させる1枚を二重計上しません。
- ポケットペアの「11.8%」はフロップ時点の値であり「リバーまで」と矛盾するため、現在のプリフロップ問題から外しています。
